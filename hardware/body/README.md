# Body (redesign)

`WildWilly_Body_P1S.3mf` -- Bambu Studio project for the redesigned body that Willie is moving
to (2026-10-14): body_lower, body_upper, dome_cap, display_bezel, servo_bar, ToF_box front and
rear, and four sonar holders. The parts are laid out flat for printing on a P1S, not assembled.
